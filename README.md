# X 黄推屏蔽器

**彻底挡住 X（Twitter）上的黄推、福利推广、车牌、裸聊等内容。**

专为中文用户设计的 Chrome / Edge 扩展，内置大量中文黄推关键词，让你刷时间线时不再被突然出现的福利姬、推广、车牌骚扰。

本项目基于优秀的开源项目 [X Focus Filter](https://github.com/vorojar/x-focus-filter) 二次开发，针对中文「黄推」场景做了大幅增强。

## 主要特点

- **超强中文黄推过滤**：覆盖福利姬、车牌、裸聊、同城可约、OnlyFans 推广等多种常见形式
- **本地运行，隐私安全**：所有内容都在浏览器本地判断，不上传任何数据
- **默认激进隐藏**：匹配到的黄推直接完全消失（也可自行调整）
- **高度可自定义**：支持自由增删关键词 + 账号白名单
- **简单易用**：基于成熟项目，界面清晰，加载后即可使用

## 安装方法

### 开发者模式加载（推荐）

1. 下载本仓库代码（或直接下载 Release 中的 zip 解压）
2. 打开 Chrome / Edge 扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目文件夹
6. 固定扩展图标到工具栏

安装后访问 [x.com](https://x.com) 即可使用。

## 使用建议

1. 安装后先去扩展的 **设置页**（点击 popup → 管理关键词与白名单）查看和补充关键词。
2. 可以把你经常看到的黄推话术补充进去，效果会更好。
3. 如果有想保留的账号（即使发黄推也想看），可以加入白名单。

## 与原项目关系

本项目是 [vorojar/x-focus-filter](https://github.com/vorojar/x-focus-filter) 的定制分支，主要变化：

- 大幅扩充中文黄推黑名单（核心改进）
- 默认行为调整为更激进的黄推过滤
- 中文界面和说明优化

原项目更适合想专注刷科技/AI 内容的用户，本项目更适合想干净刷 X、不想看到黄推的用户。

## 贡献
